5. Main Inner Workings

Homepage and product browsing

/ calls home_view, queries featured products, falls back to recent products if none are featured, and renders home.html. Product listing supports category filtering, search with Q objects, and price/newest sorting.

Cart

Logged-in users use a cart linked to their user. Guests receive a session key and use a session cart. A cart item combines product, optional size and quantity. Effective price is used for subtotal calculation.

Checkout

The form validates shipping details and payment method. The server calculates subtotal, shipping and total, creates an Order, creates its OrderItems, clears the cart, then either confirms COD or opens the Razorpay payment page.

Price and shipping rules

Discount price is used only when it exists and is lower than the original price. Shipping is ₹99 when subtotal is ₹1,499 or below, and free above ₹1,499.

Q: Why multiply amount by 100?
Razorpay expects the smallest currency unit, paise. ₹100 becomes 10,000 paise.
Q: Why not trust browser payment status?
Browser data can be modified. The server must verify the Razorpay signature using the secret key.
Q: Is it real AI or real payment?
Razorpay is sandbox/test mode. The current AI stylist is a rule-based recommender using words such as hoodie, oversized, streetwear, cargo and budget.

7. Most Likely Viva Questions and Answers

Q: Why Django?
Django gives routing, ORM, authentication, forms, templates, admin, middleware and security in one mature framework. That reduces development time for a database-driven e-commerce system.
Q: What is MTV?
Model stores data, Template presents the UI and View processes requests and responses. It is Django’s version of the MVC idea.
Q: What is manage.py?
The command-line entry point for runserver, migrate, makemigrations, test and collectstatic.
Q: What is ORM?
Object Relational Mapping maps Python model classes to database tables and lets us query using Python instead of writing most SQL manually.
Q: Why custom User model?
ZENZEE needs phone number, profile picture and bio in addition to Django’s standard authentication fields.
Q: What do migrations do?
They version-control schema changes. makemigrations creates migration files and migrate applies them to the database.
Q: What is CSRF?
Cross-Site Request Forgery protection prevents an unwanted state-changing request from another website using the user’s browser session.
Q: Why use login_required?
It protects profile, order history, wishlist and review actions from anonymous users and redirects them to login.
Q: What does WhiteNoise do?
It serves collected static CSS, JavaScript and assets directly from the Django deployment.
Q: Why does Render start with cd backend?
The Django project package config and manage.py are inside backend, so Gunicorn must run from that directory to import config.wsgi.
Q: What was the Render 500 problem?
The service started successfully, but the fresh deployment database had no schema because migrations were not run. The deployment command was updated to run migrations and collectstatic before Gunicorn.
Q: What is the dashboard?
A staff-only view protected by staff_member_required. It aggregates users, products, orders and revenue and displays recent orders.
